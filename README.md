# Bioinformatics Disease Classification

## 一、项目简介

本项目为福州大学《生物信息学》课程上机实验一：**基于多组学数据的疾病分类**。

项目计划使用 TCGA 癌症相关数据，利用机器学习算法完成疾病分类任务，并对模型的分类效果进行评估。

本项目由 8 名小组成员合作完成，最终成果包括实验代码、实验结果、PPT 汇报和研究报告。

## 二、研究目标

当前拟定的实验方案为：

**基于 RNA-seq 基因表达数据的乳腺癌肿瘤与正常组织分类研究。**

主要目标：

1. 获取 TCGA-BRCA 相关数据。
2. 完成数据清洗、样本标签匹配及特征选择。
3. 分别构建随机森林和 SVM 分类模型。
4. 评估并比较两种模型的分类性能。
5. 分析实验结果，完成 PPT 汇报及研究报告。

> 注意：目前暂定使用 RNA-seq 单组学数据开展二分类实验。是否必须使用两种及以上组学进行融合，仍待老师确认。后续将根据老师要求调整实验方案。

## 三、技术方案

### 1. 数据来源

- 数据来源：TCGA
- 数据获取平台：UCSC Xena
- 数据类型：RNA-seq 基因表达数据
- 研究对象：暂定乳腺癌（BRCA）
- 分类任务：肿瘤组织与正常组织二分类

数据集地址：https://xena.ucsc.edu/public/

### 2. 开发环境

- 编程语言：Python
- 数据处理：NumPy、Pandas
- 机器学习：scikit-learn
- 数据可视化：Matplotlib、Seaborn

预处理脚本：`src/preprocess.py`；详细输入格式、运行命令和交接边界见 [`docs/preprocessing.md`](docs/preprocessing.md)。依赖可通过 `pip install -r requirements.txt` 安装。

当前标签核对状态见 [`docs/label_validation_20261030.md`](docs/label_validation_20261030.md)：C 的清单已与 B 的最终标签表逐样本核对通过，无需重新生成预处理数据。


### 3. 机器学习算法

计划使用两种传统机器学习算法：

- Random Forest（随机森林）
- Support Vector Machine（支持向量机，SVM）

### 4. 评价指标

- Accuracy（准确率）
- Precision（精确率）
- Recall（召回率）
- F1-score
- ROC-AUC
- Confusion Matrix（混淆矩阵）

## 五、项目目录

- `data/`：数据集及相关文件
  - `raw/`：原始数据
  - `processed/`：预处理数据；当前 TCGA-BRCA 交付包位于 `data/processed/tcga_brca_20261029_v2/`，包含训练/测试矩阵、特征 ID、样本清单、审计信息和读取说明
- `src/`：Python 源代码
- `results/`：实验结果
  - `figures/`：实验可视化图表
- `docs/`：实验方案、数据说明与分工文档
- `presentation/`：PPT 和答辩材料
- `report/`：研究报告

大型原始数据及模型权重不直接上传至 GitHub，具体数据下载信息记录在项目文档中。
