# D 特征选择部分：小组汇报素材

## 适合讲述的工作内容

我负责从 RNA-seq 基因表达数据中筛选适合分类的特征，并把方法实现成随机森林和 SVM 都能使用的模块。C 提供的训练集有 976 个样本、877 位患者和 60,660 个基因，其中正常组织 88 个，原发肿瘤 888 个。

我采用两步筛选。首先删除训练数据中取值完全不变化的基因，实际去除了 2,648 个，剩余 58,012 个。然后采用 ANOVA F 得分对各基因进行单变量评分，分别保留 100、500 和 1000 个候选特征。代码能导出基因 ID、原始列索引和筛选后列位置，保证与后续模型输入一致。

由于同一患者可能有多个样本，内部验证采用患者分组的五折划分。每个训练折都重新拟合筛选器，SVM 标准化也只使用当前训练折，避免提前利用验证或测试信息。

为了给后续模型训练提供参考，我在固定参数的随机森林和 RBF-SVM 中比较了三个特征数量。按事先约定的 AUC 规则，两种模型都推荐先从 100 个基因开始。对应平均验证 AUC 分别为 0.999844 和 0.999240。这些是训练集内部的参考结果，不是最终测试集结果，正式模型与独立测试仍由 E/F/G 完成。

我还分析了不同训练折的入选重合情况。100 基因方案中有 77 个基因在五折都被选中，说明存在一批在当前数据划分中较稳定的候选特征。但单变量筛选不能捕捉全部基因联合作用，入选基因也不能直接视为经过验证的疾病生物标志物。

## 建议给组长的三页 PPT 内容

1. **方法与数据**：样本／患者／基因数量；去常量与 Top-k 两步流程；放入图 `feature_count_comparison.png`。
2. **候选特征**：使用图 `top_feature_scores.png`，解释 F 得分与 Ensembl ID；可补充“77 个基因五折均入选”的稳定性结果。
3. **特征数量比较与结论**：使用图 `k_comparison_reference.png`，标明“训练集内部患者分组五折参考实验”；说明推荐 100 个基因作为接入起点，同时保留 500／1000 的候选材料。

## 提问时的回答要点

- 为什么不直接用全部基因？本任务希望减少维度与冗余并提供可解释的候选列表；本次尚未与全基因模型基线对比，不能声称已证明预测性能提升。
- 为什么选 100？三个预设候选中，该配置在本次两种固定模型的平均验证 AUC 均最高，且符合优先较少特征的预设规则；结果差异很小，不宣称统计显著优势。
- 为什么不用 DESeq2？issue 不强制，C 的表达数据已做 log 转换，当前连续特征筛选方案与提供的数据及 sklearn 分类流程相匹配。
- 如何避免泄漏？外部测试保留；内部按患者分组；选择器和 scaler 均在每个训练折重新拟合。
- 为什么报告正常类召回？肿瘤样本较多，仅看 Accuracy 或肿瘤类 F1 容易忽略少数正常样本的分类表现。
- 这些是疾病标志物吗？目前只是用于该分类任务的统计候选特征，尚无独立实验或外部队列的生物标志物验证。
